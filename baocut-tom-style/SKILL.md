# 汤姆小课堂视频风格

先读 `/Users/fengye/workspace/baocut/fengye/BRAND.md` 和其中链接的角色设定，使用已确认的汤姆形象与配音参考。每次制作结合用户最新要求；品牌设定与用户最新意见不一致时，以最新意见为准。

对于已确认的横屏讲解形式：汤姆以半身主持形象持续在右侧出现，配合内容改变表情动作；图解在左侧，字幕、人物和关键内容互不遮挡。字幕按自然短句显示，不逐字高亮。图解应服务于讲解，少放重复旁白的大段文字。

神经网络、数学和其他适合动态演示的图解优先用 **Manim Community Edition（社区版，Python 包 `manim`）**制作，再导入 BaoCut 与汤姆、旁白、字幕合成。不要把 3b1b 原版 ManimGL 的 API 当成社区版；先小样验证渲染和导入。保留动画源码和数据，示意数据明确标注，不冒充实测；根据画面安全区设计文字和布局。需要安装依赖时遵照用户最新网络要求，使用国内镜像且绕开 Clash 代理。

保留用户认可的原成片和素材；新的视频在独立项目或输出中制作。使用 BaoCut 的视频制作、知识讲解、旁白和虚拟主持相关技能，检查成片中的画面、字幕、内容和声音衔接。

## 用户确认的横屏画面模板

制作汤姆小课堂横屏讲解片时，先读 `/Users/fengye/workspace/baocut/fengye/templates/tom-classroom-v1/README.md`，并基于其中的 `example.py` 和 `reference.png` 创建场景。该模板已获用户对静态画面及短动态样片的认可。固定标题、图解、字幕、人物区域；同一解释区先移除旧元素再显示新元素；图线不穿字，图解与数值说明分栏，切换到总结时清空图表。每个关键状态及过渡先低清渲染并实际查看，修复重叠再批量出片；无法看图不得把程序检查等同于目视通过。
