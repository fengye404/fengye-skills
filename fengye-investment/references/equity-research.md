# 个股基本面、估值与观点跟踪

研究个股时按问题选用以下方法。方法取舍与上游来源见 [upstream-methods.md](upstream-methods.md)；行情和财务时间口径见 [local-data.md](local-data.md)。不要求每次生成完整估值模型。

## 从筛选到验证

先用明确、可调整的条件缩小候选，再检查入围公司的报表和派息质量。保留筛选范围、未返回的标的及剔除理由。筛选分数只用于排序研究，不能用“高分”替代投资理由。PE/PB/股息率阈值按行业、市场与投资目的设定，不照搬美股统一门槛。

对高股息公司，把过去多年的收入、利润、每股派息和现金流放在一起看。核对股利支付率、经营现金流、资本支出、债务到期与现金余额；普通非金融企业可用自由现金流覆盖股息辅助判断。银行和保险不能机械套工业企业的流动比率、负债率或FCF标准，应看资产质量、拨备、资本充足与监管分红约束。说明高息来自稳定经营、临时分配还是股价下跌，不能把三者混为一谈。

## 先核对财报变化

对新财报比较上年同期、前期趋势和公司此前指引，检查分部、毛利/净利率、非经常损益、现金流与利润差异、营运资本和资本支出。A股季度利润/现金流常为年初至今累计值：需要单季值时，同口径相减并检查修订；不能把累计三季报与单季度数据直接比。

只有取得有日期、口径一致且当时已公开的一致预期，才能说超预期或不及预期；没有就写同比变化与自身判断，不虚构市场预期。记录“旧判断/假设→新事实→改变什么”，而非每次重新写一套互不相干的结论。

## 按企业类型选择估值

- 可比公司：先解释为什么可比，考虑业务、地区、规模、增长、盈利质量与资本结构；统一估值日、币种、股本与财务周期。展示样本和中位数/范围；负盈利等不适用倍数标未知或不适用，不当作便宜。前瞻PE与TTM EPS不能混乘来推目标价。
- 稳定非金融公司：资料充分时可用DCF，明列增长、利润率、资本支出、营运资本、折现率与永续增长假设。保留营运资本变动的经济方向，不能为方便一律取绝对值；区分FCFF配WACC与FCFE配股权成本。
- 银行/保险：优先结合PB、ROE、资本与资产质量；适用且数据充分时可用股利折现或剩余收益，不把企业FCFF模型强套金融机构。
- 周期公司：检查正常周期利润与现金流，不能以景气顶点低PE证明低估。多业务公司只有分部数据可靠且业务确有差异时才做分部估值。

折现参数与现金流币种、期限及市场保持一致；不静默使用美债利率、美国长期增长率或硬编码退出倍数。缺少关键参数时交付相对估值或情景，不补造精确价格。模型中要求折现率大于永续增长率，敏感性表逐格处理不合法组合；不能仅为了算得出结果就悄悄压低增长率。

DCF、可比和分部估值用于交叉检查，出现明显差异应解释驱动因素；不默认50/50或40/30/30加权后得到“真实价值”。报告区间和敏感假设，情景可以有条件而无概率；模型结果不等于买点。

## 观点可以被推翻

在实际研究记录中写短投资论点、支持依据与会推翻它的证据。更新时保留：日期、原预期、新事实及来源、影响哪个依据、维持/削弱/否定、建议动作和是否被用户采纳。确认与反驳证据同等记录；没有必要改动时也说明理由。

研究记录留在私人投资工作区。可建立“原预期—当前事实—偏差—下一核验条件”的简表，链接原研究和决策；不能将模型建议自动写成已成交。季度复盘可作为维护节奏建议，不自动创建日程、提醒或交易。

## 可执行流程：采集、复核、计算

本地 Python 环境有 AKShare、pandas 时，先在技能目录运行（输出路径需是尚不存在的文件，避免覆盖；原始数据保存在私人投资工作区，不上传公开仓库）：

```sh
PY=/Users/fengye/workspace/investment/.venv/bin/python
SKILL=/Users/fengye/workspace/fengye-skills/fengye-investment
"$PY" "$SKILL/scripts/equity_research.py" snapshot --symbol 600036 --timeout 20 --output /tmp/600036-equity-raw.json
```

`snapshot` 分进程调用 `stock_financial_abstract_ths`、`stock_fhps_detail_em`、`stock_value_em` 和不复权 `stock_zh_a_hist`，各自保留原始行、接口、来源、获取时间、版本和失败原因。超时或一个源失败不会伪装成成功；原始字段、单位和时间可能变动，不能把这些表直接当已验证报告。尤其同花顺财务数据有中文单位、False 缺失值和累计期；必须查财报公告核实数值、单位和公开日期，避免未来信息。分红接口的 `现金分红比例` 是每10股口径，应以描述及公告核对后换算每股；只纳入窗口内已实施的事件，明确税前、除息日和拆分影响。

把已核对的数据整理成与 `examples/equity-input-example.json` 同结构的私人JSON：每个数值有 `value`、`unit`、数据日期 `date` 和 `source`；财务指标另填首次公开或修订版本实际 `disclosed_at`，必须不晚于研究时点。每股项用“元/股”，现金流用“元”；资本支出和已付股息均填正的现金流出；三个现金流输入必须提供 period_start、period_end 与 basis，期间或口径不一致时拒算覆盖率。应使用同一期间和同一归属口径，保留原始数据和公告链接；公司历史分拆、股本变动及EPS调整先核验。缺失填 null，不以零替代。

```sh
"$PY" "$SKILL/scripts/equity_research.py" analyze --input /path/to/verified-equity-input.json --output /path/to/new-equity-analysis.json
```

计算器输出 PE=价格/TTM EPS、PB=价格/每股净资产、税前历史分配率=已实施每股现金分红/价格；非金融公司额外输出自由现金流=经营现金流−资本支出、自由现金流/实际现金股利。零或负盈利时PE为null；分母非正时对应比率为null，负经营现金流可如实呈现。银行/保险不计算工业企业FCF覆盖。手工输入及其来源原样保留，输出记录输入路径与SHA-256；报告需同时列单位、期间、公开日、同业可比口径与未核实项。该计算器不自动构造TTM、不判断未来分红或推荐、不从摘要表自动猜财务字段，不自动推算目标价。TTM股息经分拆影响核对前，只能输出算术值及提示。

**构造示例（虚构，非行情）**：20元价格、2元TTM EPS、10元每股净资产、过去12个月每股派0.8元，得到PE 10、PB 2、税前历史分配率4%；同期经营现金流1.2亿元、资本支出0.4亿元、实付股利0.5亿元，自由现金流0.8亿元、覆盖1.6倍。这些计算不能证明股票便宜或派息可持续。报告还需根据行业检查盈利质量、资产负债、估值基准、竞争和下行风险。

对于DCF或同业比较，先确认企业类型和输入完整；列明现金流与折现率同币种、FCFF配WACC、未来每年增长及资本开支、净债务和稀释股数，永续模型要求折现率大于永续增长率。输出敏感性区间与每项来源；没有可靠假设不生成目标价。以上脚本只做基础指标，不实现DCF或自动筛股。
