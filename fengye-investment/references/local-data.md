# 本地取数与验收

用于行情失败重试、实时ETF分析、历史总回报和个股财务对齐。以下是本地已遇到的问题与可复用办法，不是所有接口永久有效的保证。

## 环境与来源

先复用投资工作区 `.venv/bin/python`，记录当前 AKShare 版本。先检查现有脚本的输入输出，避免无意覆盖历史快照。行情由 AKShare/同花顺核验；产品规则、费率与公司事件需要时查基金管理人、指数公司、交易所或公司公告，网页搜索摘要不能替代行情。

每份快照至少保留：接口及参数、代码与产品类型、源端行情时间、查询时间及时区、币种、价格/复权口径、字段单位、覆盖范围、缺失与失败原因。查询成功或刚写入文件不代表行情新鲜。源端未提供某字段自己的时间戳时记为未知，不能用整行报价时间证明IOPV同步。

## ETF实时窄查询

2026-10-29本地 AKShare 1.19.1 的 `fund_etf_spot_em()` 全市场分页失败，但缩小服务器请求范围后成功。全表失败时可以采用这个恢复方向：

1. 检查当前函数源码与分页实现，而不是重复发起相同全市场请求。
2. 仅对本次ETF查询，将东方财富 `clist/get` 的 `fs` 改为目标证券列表，例如 `i:1.515080,i:1.512890`；其中市场编号须按上市市场核验。保留AKShare当前字段选择与解析。
3. 这是请求层缩小范围；下载全表后再筛选不会避开分页失败。若临时适配请求，限制URL与作用范围，结束时恢复，不把全局补丁留给其他取数任务。
4. 验证返回代码集合、报价日期与源更新时间；请求多只时逐只保留失败，不能把部分成功描述为全部成功。必要时使用独立进程以隔离请求适配。

可核验字段包括最新价、开高低、昨收、买一卖一、成交量额、换手、IOPV、源更新时间。以下公式保持口径明确：

- 观察溢价 = `最新价 / IOPV - 1`；拟买入成本参考可用卖一替代最新价，二者分别标注。
- 相对价差 = `(卖一 - 买一) / ((卖一 + 买一) / 2)`；先检查价格为正、卖一不低于买一。
- 不直接信任“基金折价率”字段的正负方向，核对源定义或自行计算。
- IOPV是参考估值。缺失、异时或底层市场休市时，不据此断言可套利或已通过实时买入条件。

该恢复办法只说明指定接口曾可用，不承诺数据无延迟；仍需保存返回时间。不得因当日涨幅大就认定溢价大。

## 历史价格与公司行为

- 本地 `stock_zh_a_hist_tx` 的515080历史前复权出现减去累计现金的形式；直接计算前复权价格比会扭曲早期收益率。对新产品或新供应商，先抽查至少一个分红/拆分事件及普通交易日，再决定复权序列适用范围。
- 真实账户总回报优先原价、持仓份额、现金和应收股息记账。除息日确认权益，到账日才成为可用现金；不能把现金分红加到已含该收益的序列上。
- 拆分按权益事件调整份额；若生效日无行情，核对官方生效时点和复牌日映射。不能把拆分后的价格减半当亏损，也不能遇到非交易日就漏掉事件。
- 比较同日收益时对齐交易日并记录缺失。共同日期交集会漏掉单边停牌期间的风险；不应把删去缺行情的日期称作完整逐日回撤模型。
- `fund_etf_hist_sina` 等返回的最新日期可能停在前一交易日；腾讯日线也可能尚未更新。逐次核对末行，不以接口名称推定覆盖今日。
- 本机曾在同进程多线程初始化Sina相关取数时触发 mini_racer 崩溃；该路径优先顺序调用或独立进程，不用重复线程并发重试。

验收关注经济不变量：拆分前后份额乘价格守恒；除息后价格加应收的财富变动不能凭空多一份股息；现金不为负；委托单位符合对应市场和产品规则。价格本身有真实涨跌时，以隔离事件的构造案例检查记账，而非要求实际市价完全不变。

## 个股财务与股息

财报期、首次公告日、修订日和查询日分别保留。历史策略只能用信号时已公开的信息；只有当前修订版而无历史版本时，披露无法完全恢复当时可知数据。PE标注TTM/静态/预测口径，负盈利时不按低PE排序；行业比较考虑银行、周期股等财务结构差异。

股息区分预案、已实施、除息与到账。TTM现金分配率统一用明确窗口内已实施每份现金除同一参考价，说明税前/税后；特殊分红或派息错位可能使滚动窗口包含多次分配，不应直接年化成未来承诺。空表是未知，不能写“从未分红”。

数据验收未过时，仍可交付已核实部分和局限，但不补造实时判断、总回报或精确买入条件。文稿格式检查不能替代这些原始数据核验。
